# SingularisInteraction

Singularis 系列的标准参考实现与面向交互领域的通用基础设施插件（UE5）。插件不内建任何具体交互业务（拾取、开关、乘坐、开门等），只提供交互会话骨架、数据契约、事件流与控制 / 表现接入点：具体副作用由项目侧以交互响应子类实现，过程规则由项目侧以交互会话子类扩展，表现由项目侧以视图实现。

架构核心：**协议只讲意图，不讲手势**。控制端把任意来源（玩家输入 / AI / 脚本）翻译为中性意图，逻辑端以可插拔会话把意图推进为交付事件；手势识别不进入协议，不引入阶段枚举与时钟容差。

## 特性

- **意图驱动 (Intent-Driven)**：主张 / 撤回 / 连续值三意图加开放标签域，不引入阶段枚举。
- **会话化 (Session-Oriented)**：控制端提交单次请求，逻辑端把它升级为具备建立、推进、定格、达成与中止的会话；单次请求只是会话的最小形态。
- **会话可扩展 (Pluggable Session)**：内建瞬时 / 长按 / 连点 / 轴积分 / 拖动 / 脉冲六族为锁定参考实现；新形态经会话基类新增子类，框架零改动。
- **事件流 (Event Stream)**：会话事件经事件分发器本地广播并通知世界子系统；推进为唯一连续事件。
- **本地会话 (Local Session)**：本地玩家在本地派生并推进镜像会话，产出零延迟本地会话流；不消费会话端状态与事件。
- **AI 一等公民 (AI Parity)**：玩家、AI 与脚本同一提交入口、同一时钟；附内建行为树任务。
- **三元分离 (Logic — Presentation — Control)**：逻辑 / 表现 / 控制依赖单向，表现仅依赖两个视图契约。
